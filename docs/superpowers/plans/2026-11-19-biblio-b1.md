# Biblio B1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Plateforme web auto-hébergée de cours, d'entraînement et d'entraide pour la promo B1.

**Architecture:** Monolithe Next.js (App Router) ; la logique métier vit dans `src/server/*` (fonctions pures + accès Drizzle), appelée par des server actions et route handlers fins. SQLite unique dans `storage/data.db` avec FTS5. Le script d'import est un CLI `tsx` qui réutilise les mêmes modules serveur.

**Tech Stack:** Next.js 15, React 19, TypeScript strict, Tailwind CSS 4, Radix UI, better-sqlite3, Drizzle ORM, zod, @node-rs/argon2, simple-git, pdfjs-dist, mammoth, adm-zip, react-pdf, react-markdown + rehype-katex + Shiki, cmdk, vitest.

**Spec:** `docs/superpowers/specs/2026-11-19-biblio-b1-design.md` (et `consignes.md`).

## Global Constraints
- Variables `.env.example` : `ADMIN_INVITE_CODE`, `C_PROF_REPO_URL`, `PORT`, `STORAGE_PATH` (+ `SESSION_SECRET`).
- Défauts : `STORAGE_PATH=./storage`, `C_PROF_REPO_URL=https://github.com/S-L-A-K-E-R/C_courses`, `PORT=3000`.
- Démarrage : `npm install && npm run dev` ; production `npm run build && npm start` ; import `npm run import`.
- Aucun service cloud ; Node ≥ 20 ; doit tourner sur Linux (Crostini) et Windows (dev).
- Rôles exacts : `admin`, `member`. Statuts de progression exacts : `todo`, `doing`, `mastered` (libellés « À faire », « En cours », « Maîtrisé »).
- Types de contenu exacts : `course`, `photo`, `exercise`, `exam`, `note` (libellés « Cours », « Photo », « Exercice C », « Annale PDF », « Note/Question »).
- Formats d'upload : `.pdf .md .c .h .py .txt .jpg .jpeg .png .webp .docx .pptx` ; taille max 50 Mo.
- Interface en français.
- Toute entrée utilisateur validée par zod ; toute page hors `/login` et `/invite/*` exige une session.

## Review Focus
- Jeton d'invitation réutilisé au-delà de `max_uses`, expiré ou révoqué → refus clair, aucun compte créé (test Task 2).
- Nom de fichier uploadé avec `../` ou caractères spéciaux → stocké sous un nom généré, jamais hors `storage/uploads` (test Task 3).
- Ré-exécution de `npm run import` → aucun doublon (sha256) et les corrections appariées restent liées (test Task 6).
- PDF sans texte extractible (scan) → document importé avec `text = ''`, sans crash ni exercice fantôme (test Task 5).
- Requête de recherche contenant des caractères spéciaux FTS5 (`"`, `*`, `-`, `:`) → pas d'erreur SQL, résultats ou liste vide (test Task 9).
